# To-Do List Application

A simple To-Do List application where users can efficiently manage their tasks by adding, editing, and deleting plans. This project is built using Python with FastAPI for the backend and JavaScript for the frontend.

## Project Overview

The main objective of this project was to implement a functional task management application, focusing on connecting the backend (FastAPI) to the frontend using JavaScript. Users can perform basic CRUD (Create, Read, Update, Delete) operations on their to-do lists, making it easier to stay organized and productive.

## Features

### Implemented:
- Add Plans: Users can create a new plan and add it to the to-do list.
- Edit Plans: Modify the details of an existing plan.
- Delete Plans: Remove completed or unwanted plans from the list.

  
## Installation

Clone the repository:
```
git clone https://github.com/your-username/to-do-list.git  
cd to-do-list
```

Set up the Python environment:
```
python -m venv env  
source env/bin/activate  # For Linux/Mac  
env\Scripts\activate  # For Windows
```

Run the FastAPI server:
```
uvicorn main:app --reload
```
